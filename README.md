# PhoneAccounting - نظام محاسبة الهواتف

نظام محاسبي متكامل لإدارة مبيعات الهواتف والإكسسوارات وقطع الغيار، مع دعم نقاط البيع، المشتريات، المخزون، الصيانة، والتقارير.

## المميزات الرئيسية

| الوحدة | الوصف |
|----------|-------|
| **نقطة البيع (POS)** | واجهة كاشير سريعة للبحث، إضافة للسلة، اختيار الزبون، الدفع، وطباعة الفاتورة |
| **المنتجات والمخزون** | إدارة الأصناف، التصنيفات، الأسعار، المخزون، تنبيهات النفاد |
| **المشتريات** | فواتير شراء من الموردين، سلة مشتريات، سجل المشتريات |
| **المبيعات** | عرض فواتير البيع، التفاصيل، البحث، التصدير |
| **الصيانة** | استلام أجهزة، تتبع حالة الإصلاح، التسليم، الفوترة |
| **الموظفون** | إدارة الحسابات، الأدوار، الصلاحيات، تفعيل/إيقاف |
| **الجرد** | عرض أرصاص الأصناف، القيمة الإجمالية، تنبيهات منخفضة/نافدة، طباعة تقرير |
| **التقارير** | مبيعات، مشتريات، أرباح، ملخصات يومية/شهرية |
| **الإعدادات** | شركة، عملة، جهاز، نسخ احتياطي |

## التقنيات

- **.NET 10** (WPF)
- **Entity Framework Core** + **SQLite** (قاعدة بيانات محلية)
- **CommunityToolkit.Mvvm** (MVVM)
- **Material Design** / أسلوب Apple مخصص
- **FlowDirection RightToLeft** (دعم عربي كامل)

## التشغيل

```bash
# استنساخ المستودع
git clone https://github.com/YOUR_USERNAME/PhoneAccounting.git
cd PhoneAccounting

# البناء والتشغيل
dotnet build src/PhoneAccounting.App/PhoneAccounting.App.csproj -c Release
dotnet run --project src/PhoneAccounting.App/PhoneAccounting.App.csproj -c Release
```
