# DEPLOY-PAIRING — وثيقة النشر والاقتران (الإطلاق المرحلي §11، الزوج)

> **التاريخ**: 2026-09-16 — **المرجع**: `خطة-الخطوة-القادمة.md` (§11)، `SYNC-DESIGN.md` (البند 4، 8.4، §11، 14، 1.16–1.21)، `دراسة-الخطوة-القادمة.md`.
> **المبدأ**: كل بند هنا إمّا مقيس من الكود أو مثبَّت بفحص على جهاز حقيقي — لا وصف افتراضي.
> رقم الفاتورة يبدأ الآن ببادئة الجهاز (حسم H1، `InvoiceService`): `F-/P-/R-/V-<بادئة 8 خانات>-<تاريخ>-<عدد>`.

## 2. إعدادات المزامنة لكل جهاز (تُضبط على قاعدة كل جهاز)

| المفتاح (AppSettings) | القيمة | ملاحظة |
|-----------------------|--------|--------|
| `DeviceId` | (يُنشأ تلقائياً) | لا يُغيَّر — هوية المصدر وبادئة الفواتير |
| `DeviceRole` | `MainServer` (على الرئيسي) / `Cashier` (على الكاشير) | قرأه `Session.Device` |
| `SyncPort` | `45678` | منفذ الاستماع — **الافتراضي الفعلي في الكود** (`SyncPeer.DefaultPort=45678`) |
| `SyncSecret` | سر مشترك واحد على كل الأجهزة | **إجباري برمجياً (1.19)** — غيابه أو تساويُه القيمة الاحتياطية المعروفة = رفض كامل للمزامنة (خادم/عميل/فحص) حتى يُضبط من شاشة الإعدادات. **القاعدة الحالية بلا سرّ → لن تزامن حتى يُضبط** |
| `SyncPeers` | `عنوان-الجهاز-الآخر:45678` (قوائم مفصولة بفواصل) | شكل `host:port` — منتجات المزامنة تُقرأ بهذا النمط |
| `AutoSync` / `SyncIntervalMinutes` | `true` / `5` | الخدمة الخلفية الدائمة |

> **ملاحظة فجوة (أُغلقت — 1.18)**: لم يعد مطلوباً تحرير الجدول يدوياً — الأقسام في `SettingsView`
> «المزامنة والاقتران» (للمدير فقط) تحرّر `DeviceRole/SyncPort/SyncSecret/SyncPeers` مباشرة عبر
> `AppSettings` بنفس النمط الذي يقرؤه المستوى الزمني. الأقران تُكتب بالتنسيق `host:port` بفواصل
> ويطبعها `NormalizePeers` (فحص آلي PAIRING). ما زالت تُنفَّذ خطوة بذر `DeviceId` بتشغيل أولي.
> **ملاحظة**: مفتاح سرّ موجود مسبقاً تُظهره الشاشة في خانة السر (نصّ مُخفى) قابلاً للتغيير.

## 3. خطوة 1 — تجهيز MAIN الحقيقي

1. نسخ نسخة Release إلى حاسبة MAIN وتشغيلها مرة واحدة (ضمان بذر `DeviceId` + admin).
2. في شاشة «الإعدادات → المزامنة والاقتران»: `DeviceRole=MainServer` + `SyncSecret` (سرّ مشترك قوي) + `SyncPort=45678` + حفظ.
3. فتح المنفذ `45678` في جدار الحماية — قاعدة **واردة** على كل مضيف: `TCP 45678`، `RemoteAddress=LocalSubnet`،
   `Profile=Private` (الأمر الجاهز والتحقق في §9 بند 4؛ لا «كل العناوين» ولا ملف شخصي عام).
4. تجربة يدوية مقفلة على MAIN وحدها: بيع → إقفال اليوم (`CloseDay`) → منع تعديل → إلغاء/مرتجع → تسوية
   (`StockAdjustment` بسبب إجباري).
5. معيار قبول الخطوة: مصافحة مع قريب واحد تنتهي بنجاح و`pulled/pushed` محدَّثان (شاشة «المزامنة»).

## 4. خطوة 2 — الزوج (كاشير P)

1. نسخ نسخة Release إلى حاسبة الكاشير وتشغيلها مرة واحدة (يُنشأ لها `DeviceId` مختلف).
2. في «الإعدادات → المزامنة والاقتران»: `DeviceRole=Cashier` + نفس `SyncSecret` + `SyncPort=45678` + حفظ.
3. ضبط `SyncPeers` على كلا الجهازين ليشمل كلٌّ الآخر (`host:port`) — واجهة الإعدادات، أو القائمة النصية في الشاشة.
4. «زامن الآن» يدوياً حتى المصافحة الناجحة ثم دورية تلقائية (5 دقائق).
5. بيع حقيقي على الكاشير → الرقم ببادئته يصل MAIN بلا خرق الفهرس الفريد `InvoiceNumber`.
6. معيار قبول الخطوة: يوم كامل بلا تعارض، وبادئة الجهاز حاضرة في فواتير الطرفين.

## 5. إقفال كل ليلة (ترتيب النسخ — قرار R3)

1. `CloseDay` على كل جهاز (قفل الاعتماد).
2. المزامنة **(تسبق النسخ الليلي)** — «يُرسَل المعلَّق أولاً ثم تؤخذ النسخة».
3. مقارنة ليلية: `FinancialTotals.Verify` (جمع توافقي) + عدّ فواتير اليوم — لا فجوة.
4. النسخ الليلي على MAIN فقط (الاحتفاظ آخر 30)، حدّ الخسارة عملياً بعد المزامنة = دقائق.

## 9. قائمة فحص ما قبل التشغيل + بروتوكول اليوم الأول (من «دراسة-الخطوة-القادمة»)

> المصدر: `docs\دراسة-الخطوة-القادمة.md` (بحث ويب/وثائق رسمية 2026-09-16، المصادر في قسم 7 هناك).
> تُنفَّذ على **كلا** الجهازين قبل خطوتي §3/§4.

**أ. فحص الشبكة (على كل جهاز)**: `ipconfig /all` وسجّل الاسم + IPv4 + MAC. الحجز في الراوتر
(DHCP Reservation: MAC ← IP ثابت) أفضل من IP يدوي؛ أطفئ «عناوين MAC العشوائية» بمنافذ Ethernet.
تحقق: `ipconfig /release; ipconfig /renew` ثم نفس الـ IP. مراجعة الحجوزات سنوياً.

**ب. تزامن الساعة (تاريخ الفاتورة من ساعة الجهاز)**: تأكد «مزامنة تلقائية مع خادم إنترنت»
(الافتراضي `time.windows.com`) ثم `w32tm /query /status` و`w32tm /stripchart /computer:time.windows.com /samples:5 /dataonly`
(انحراف ≈ 0). انحراف بسيط لا يمسّ الترتيب المنطقي (Seq)، لكنه يمسّ **التاريخ** — لا تقبل خطأ يوم.

**ج. قاعدة جدار الحماية — نفس أمر كلا الجهازين (idempotent، يُعاد بلا ضرر)**:
```powershell
New-NetFirewallRule -Name 'PhoneAccounting-P2P-45678' -DisplayName 'PhoneAccounting P2P Sync (TCP 45678)' `
  -Direction Inbound -Action Allow -Protocol TCP -LocalPort 45678 -RemoteAddress LocalSubnet -Profile Private
Get-NetFirewallRule -Name 'PhoneAccounting-P2P-45678' | fl Name,Direction,Action,Profile,Enabled
Get-NetFirewallPortFilter -AssociatedNetFirewallRule 'PhoneAccounting-P2P-45678'  | fl Protocol,LocalPort
Get-NetFirewallAddressFilter -AssociatedNetFirewallRule 'PhoneAccounting-P2P-45678' | fl RemoteAddress
Test-NetConnection <آيبي-الجهاز-الآخر> -Port 45678   # False قبل القاعدة (سلبي شرعي)، True بعد فتح التطبيق
```
أسس: النطاق `LocalSubnet` لا «الكل»؛ الملف الشخصي `Private` لا `Public`؛ لا حاجة لقاعدة صادرة (Stateful).

**د. السرّ المشترك (256 بت / 32 بايت) — توليد على MAIN ثم إدخال متطابق على الجهازين بنافذة واحدة**:
```powershell
$bytes = New-Object byte[] 32; [System.Security.Cryptography.RandomNumberGenerator]::Fill($bytes)
([BitConverter]::ToString($bytes)).Replace('-','')   # 64 خانة سداسية
```
لا يُخزَّن في ملف نصي على الجهازين (مدير كلمات مرور + وصف/تاريخ/أجهزة). **التدوير = إخراج جهاز**:
لتجريد أي جهاز تُغيَّر القيمة على كل الباقين في نفس النافذة ثم يُعاد تشغيل التطبيق.

**هـ. نسخة نقطة العودة قبل الاقتران**: نسخة `BackupService` (VACUUM INTO) + `PRAGMA integrity_check=ok`
+ عدّ فواتير اليوم في النسخة = عدّ الأصل. النسخة بلا استرجاع مُجرَّب «أمل» — Restore Drill ربعي (R2).

**و. بروتوكول اليوم الأول (تسلسل فحوص §5 في الدراسة — بلا تجاوز خطوة)**:
ضبط MAIN ← ضبط الكاشير (نفس السرّ) ← `SyncPeers` متقابل ← «زامن الآن»: مصافحة + `pulled/pushed` →
بيع حقيقي على الكاشير (بادئته) → وصوله MAIN بلا خرق `InvoiceNumber` → بعد الدوام: إقفال اليوم →
**المزامنة تسبق النسخة** ← `FinancialTotals.Verify` + عدّ اليوم ← نسخة MAIN.
قرار القطع: مصافحة فاشلة بعد فحص القواعد 4–6 → «لا تفتح §11» وعُد للقائمة؛ تلاحم + يوم كامل بلا تعارض → GO.
تعارض وحيد: شاشة الخلافات (1.13) وحسم اليوم نفسه.
